# Public synthetic calibration fixtures

These DWG/DXF files contain only program-generated geometry from the Field CAD demo: a 120 m line beginning at synthetic WCS (300000, 2770000), rectangles, a circle and an English label. They contain no user engineering drawing or project data.

The simple geometry was generated by this project and saved as standard AutoCAD 2018 (AC1032) DWG/DXF using AutoCAD 2027. The normalized DXF is also embedded in `src/calibration.js` for the built-in demo. Units are meters (INSUNITS=6). Both have 11 model entities. Run `node scripts/verify-calibration.mjs` to check DWG and DXF with the shared CAD core.

These small fixtures are for engine compatibility tests, not large-file or engineering-drawing acceptance. Distributed with the project under GPL-3.0.
